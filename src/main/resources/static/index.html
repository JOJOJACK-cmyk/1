김포 상권 개폐업 대시보드

지방행정 인허가 데이터 기준 추정치입니다. 폐업 신고 누락·지연이 있을 수 있어요.

아직 적재된 데이터가 없어요

인허가 CSV를 적재하면 이 화면이 채워집니다. 먼저 샘플 데이터로 화면을 확인해 보세요. 실제 김포 통계가 아닌 가짜 데이터예요.

실제 김포 데이터로 적재하려면

import/ 폴더에 CSV를 넣고, 실행 중인 서버를 먼저 종료한 뒤 아래 인수로 다시 실행하세요. (같은 DB 파일을 프로그램 두 개가 동시에 열 수 없어요.)

gradlew bootRun --args="--app.import.path=import/"

IntelliJ 라면 실행 구성의 프로그램 인수에 --app.import.path=import/ 를 넣으세요.

동네 필터는 모든 카드에, 업종 필터는 ‘연도별 추이’와 ‘읍·면·동 비교’에 적용돼요.
